# 채점 기준

**학습자가 답하기 전에 이 내용을 인용하거나 힌트로 쓰지 않는다.** 예측 질문을 낸 뒤, 학습자의 답을 채점할 때만 참고한다.

## 미응답 질문: 아이템 10만 개의 GC 마킹 비용 (02-L05로 검증)

- **설계2가 가장 쌈.** 참조 필드가 없는 struct 배열은 pointer-free로 할당되어 내용물을 훑지 않는다.
- 설계3은 struct 안에 `string` 참조가 하나 있어서 **배열 전체가 스캔 대상**이 되고, 문자열 10만 개를 방문해야 한다(문자열 내부는 참조가 없어 더 훑지는 않음). 설계1은 `Item` 객체 10만 개 + 참조 배열을 방문한다.
- 따라서 대략 **설계2 < 설계3 ≤ 설계1**. 이름이 소수의 공유 문자열이면 설계3이 훨씬 싸진다.
- 핵심 포인트: "참조 필드 하나가 배열 전체를 GC 스캔 대상으로 만든다", "비용은 살아있는 객체 수와 참조 수에 비례".
